\# Stay-Hub – Dormitory Management System



\## Project Description

Stay-Hub is a web-based dormitory management system designed to help administrators manage rooms, tenants, billing, utility records, and tenant clearance.



\## Technologies Used

\- PHP

\- MySQL

\- HTML

\- CSS

\- JavaScript

\- XAMPP



\## Main Features

\- User Management

\- Room Management

\- Tenant Management

\- Monthly Billing

\- Utility Metering

\- Tenant Clearance

\- Reports



\## Local Setup

1\. Install XAMPP.

2\. Copy the project folder into `C:\\xampp\\htdocs`.

3\. Start Apache and MySQL.

4\. Create the database named `stayhub\_db` in phpMyAdmin.

5\. Import the project's SQL database file, if available.

6\. Configure the database connection in `db.php`.

7\. Open `http://localhost/finalproject/` in your browser.
